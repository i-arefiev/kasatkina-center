# Тема «Центр физиотерапии доктора Касаткиной»

Классическая тема WordPress. Страницы собираются из стандартных блоков редактора, поэтому администратор правит тексты и картинки прямо на странице, без HTML.

## Где что редактируется (для администратора)

| Что | Где |
|---|---|
| Тексты и фото на страницах | Страницы → нужная страница → клик по тексту/картинке (картинка: «Заменить») |
| Новая секция на странице | В редакторе: «+» → «Паттерны» → «Касаткина: блоки сайта» |
| Услуги, цены, показания, ЧаВо | Раздел «Услуги» (новые услуги сами появляются на главной и в списке) |
| Адрес, телефоны, почта, лицензия, карта, куда слать заявки | Внешний вид → Настроить → «Контакты и общие тексты» |
| Логотип в шапке и подвале | Внешний вид → Настроить → «Свойства сайта» |
| Меню | Внешний вид → Меню (области «Главное меню» и «Меню в подвале») |
| Заявки с форм | Раздел «Заявки» (дублируются письмом) |
| Видео о центре | Кнопка со стилем «Видео» или «Видео: круглая кнопка play»: ссылка на .mp4 из медиатеки, YouTube, Rutube или VK — ролик откроется в окне |
| Метрика, Google Analytics, коды вебмастеров, описание для поисковиков | Внешний вид → Настроить → «Аналитика и вебмастера» |
| Шаги «Как проходит процедура» на страницах услуг | Создать синхронизированный паттерн с названием «Шаги процедуры» — он заменит шаги по умолчанию |

Краткая памятка есть и на главной странице консоли («Как редактировать сайт»).

## Установка на чистый WordPress (прод)

1. Установить WordPress (русская версия), загрузить тему (`npm run zip` → «Внешний вид → Темы → Загрузить») и активировать.
2. Перенести услуги из беты: в бете «Инструменты → Экспорт → Услуги» → файл; на новом сайте «Инструменты → Импорт → WordPress» → файл, отметить «Скачать и импортировать файлы вложений». (Ключи полей услуг не менялись — цены, показания, ЧаВо переносятся как есть.)
3. «Внешний вид → Настройка сайта» → все галочки → «Выполнить». Мастер создаст страницы, меню, перенесёт картинки, логотипы, 4 статьи со старого сайта, сделает адреса услуг как на старом сайте. Запускать повторно безопасно.
4. Проверить «Контакты и общие тексты» (особенно «Куда отправлять заявки»), опубликовать «Политику конфиденциальности» («Настройки → Конфиденциальность»), поставить SMTP-плагин.
5. «Настройки → Чтение» — убрать «Попросить поисковые системы не индексировать сайт».

## Установка и переход с бета-версии

1. Загрузить тему (папку `kasatkina-theme` или архив из `npm run zip`) и активировать.
2. **Внешний вид → Настройка сайта** → «Выполнить». Мастер:
   - переносит картинки темы в медиатеку;
   - создаёт страницы «Главная», «О медцентре», «Руководитель» (`/leader/`), «Услуги», «Статьи» из паттернов;
   - назначает главную и страницу статей, включает ЧПУ `/%postname%/`, создаёт меню.
3. На сайте с бета-версией существующие страницы содержат старую разметку (блоки «Произвольный HTML»). Чтобы заменить её новой, отметьте «Перезаписать содержимое уже существующих страниц» — прежнее содержимое сохраняется в «Редакциях» каждой страницы.
4. Проверить «Контакты и общие тексты», особенно «Куда отправлять заявки».

Данные услуг (цены, показания, ЧаВо) из беты сохраняются: ключи полей не менялись.

## SEO и переезд со старого сайта

- **Адреса как на старом сайте:** `/about/`, `/leader/`, `/services/<ярлык>/`, `/articles/<ярлык>/` (мастер включает структуру `/articles/%postname%/`). Ярлыки услуг и статей должны совпадать со старыми.
- **Редиректы 301:** `/about/leader/` → `/leader/`, `/smi-o-nas` → блок СМИ на главной (inc/seo.php); адреса без слэша WordPress перенаправляет сам. Прочие — плагином Redirection (там же журнал 404).
- **Подтверждение прав:** файлы `yandex_406edd5ae9992112.html` и `googlec2ac1c87db8b0152.html` со старого сайта отдаются из папки `verification/`.
- **Яндекс.Метрика** 94136155 с теми же настройками (вебвизор и т. д.); цели `booking_sent` (заявка отправлена) и `video_play`. Для вошедших в админку счётчик не выводится.
- **Разметка** MedicalClinic на главной; meta description и Open Graph — если не установлен SEO-плагин (при Yoast/Rank Math тема их не дублирует).
- `assets/video/promo.mp4` — ролик со старого сайта, индекс перенесён в начало файла (faststart): воспроизведение начинается до полной загрузки.

## Устройство

```
inc/            PHP-логика (см. комментарий в functions.php)
blocks/         собственные серверные блоки: иконка, крошки, сетка услуг, контакты, форма, карта, лицензия
patterns/       готовые секции (паттерны) — из них собираются страницы
template-parts/ части шаблонов (карточка статьи, секция записи, шаги процедуры)
src/main.css    исходник стилей (Tailwind 3 + стили блоков)
src/build-patterns.py  генератор patterns/*.php
assets/css/main.css    собранные стили (в репозитории — на сервере Node.js не нужен)
assets/js/      main.js (сайт), editor-blocks.js (редактор, без сборки)
```

- **Стили.** Tailwind собирается в статический файл: `npm install`, затем `npm run build` (или `npm run watch`). CDN-версия Tailwind больше не используется. Классы, которых нет в файлах темы, в CSS не попадут, поэтому новые классы добавляйте в паттерны или шаблоны, а не через «Дополнительные CSS-классы» в редакторе.
- **Паттерны** генерируются скриптом: правьте описание секций в `src/build-patterns.py`, затем `npm run patterns && npm run build`. Скрипт следит, чтобы разметка блоков была валидной для редактора (иначе будет «Блок содержит неожиданное содержимое»). Изменения паттернов не трогают уже созданные страницы.
- **Стили блоков**, которые выбирает администратор: кнопки («Зелёная со стрелкой», «Зелёная», «Контурная», «Видео»), списки («Галочки в карточках», «Галочки»), картинки («Плитка с подписью»).
- **Формы** отправляются на `admin-post.php?action=kasatkina_booking`. Защита: скрытое поле-ловушка и не чаще одной заявки в 20 секунд с одного IP. Если письма не приходят, заявки всё равно видны в разделе «Заявки»; для надёжной почты поставьте SMTP-плагин.
